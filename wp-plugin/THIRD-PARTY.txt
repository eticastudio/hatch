Hatch third-party components
===========================

Hatch is licensed GPL-2.0-or-later. See LICENSE in this folder.

Everything in this plugin was written for Hatch, except the third-party
components listed below. The versions are the ones pinned in package-lock.json
in the public source repository, https://github.com/eticastudio/hatch.


1. Admin screen (build/admin)
-----------------------------

The admin screen is built from admin-react/src. It imports only React, wp-element
and wp-i18n, which WordPress core provides at run time (see
build/admin/index.jsx.asset.php). No third-party code is bundled into it.
