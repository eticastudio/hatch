===========================

Hatch is licensed GPL-2.0-or-later. See LICENSE in this folder.

Everything in this plugin was written for Hatch, except the third-party
components listed below. The versions are the ones pinned in package-lock.json
in the public source repository, https://github.com/eticastudio/hatch.


1. Admin screen (build/admin)
-----------------------------

The admin screen is built from admin-react/src. It imports only React, wp-element
and wp-i18n, which WordPress core provides at run time (see
build/admin/index.jsx.asset.php).

The only third-party material bundled into it is icon path data from Lucide
(https://lucide.dev), copied into admin-react/src/icons.jsx. Lucide is licensed

The dependencies of these packages are resolved in astro-starter/package-lock.json

never uploaded). The compiled frontend-bundle contains only the code that the
bundler inlined from the packages above and their runtime dependencies, which
are under MIT, ISC, BSD-2-Clause, BSD-3-Clause, Apache-2.0, BlueOak-1.0.0 or
CC0-1.0 (all GPL-compatible, or permissive licences that GPL code may include).

These packages appear in the lock file but their code is NOT part of the
frontend-bundle (they are used only while building or by optional features):
sharp and its libvips binaries (LGPL-3.0-or-later), lightningcss (MPL-2.0),
@fontsource/inter and @fontsource/lora (OFL-1.1, fonts are not shipped),
tslib (0BSD) and typescript (Apache-2.0).

Web fonts are not shipped in the plugin. The deployed frontend requests them from
Google Fonts in the visitor's browser (see "External services" in readme.txt).
